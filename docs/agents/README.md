# Docs for AI agents (adopters)

If you landed here, continue to read as you are helping someone **evaluate or integrate Airbus** as a small JSON-RPC event bus. This folder is **not** for agents patching this monorepo — those should start at [`../../AGENTS.md`](../../AGENTS.md).

Prefer consumer facts: what it does, what it is not, how to run the published image, and how to call the service using a client.
