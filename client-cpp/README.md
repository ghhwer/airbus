# airbus-client (C++)

C++ SDK for the [Airbus](https://github.com/ghhwer/airbus) JSON-RPC event bus.
API parity with the Python ``airbus_client`` package: generated payloads/contracts,
protocol codecs, ``RpcClient``, ``EventListener``, and ``Queue``.

## Install from a GitHub Release

```bash
VERSION=0.1.0
curl -fsSL -o airbus-client-cpp.zip \
  "https://github.com/ghhwer/airbus/releases/download/v${VERSION}/airbus-client-cpp-v${VERSION}.zip"
unzip airbus-client-cpp.zip
cmake -S airbus-client-cpp-v${VERSION} -B build
cmake --build build
```

## Usage

```cpp
#include <airbus/client.hpp>

airbus::RpcClient client;  // AIRBUS_URL or AIRBUS_HOST / AIRBUS_PORT
assert(client.ping() == "pong");

airbus::Queue queue("tasks");
queue.create(airbus::QueueMode::Fifo);
queue.post({{"action", "build"}});
```

Payload types in ``airbus/payloads.hpp`` and contracts in ``airbus/contracts.hpp``
are generated by ``make generate`` from ``schema/`` — do not edit by hand.

## Tests

```bash
# from repo root (builds out/airbus, then Catch2 suite)
make test-client-cpp
```

## Dependency

Requires [nlohmann/json](https://github.com/nlohmann/json) (≥ 3.11). Release zips
vendor ``third_party/nlohmann/json.hpp``. From a git checkout, CMake can FetchContent it.

The daemon is distributed separately (container image or ``cargo`` / ``make build``).
